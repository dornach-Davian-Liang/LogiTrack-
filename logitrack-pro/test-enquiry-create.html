🧪 New Enquiry 功能测试

📋 测试说明

本页面用于测试 New Enquiry 表单的以下功能：

  • 多港口选择（POL/POD）支持数组格式 polIds/podIds
  • POD Country 自动映射功能
  • 销售国家和销售负责人级联选择
  • Enquiry 数据成功提交到后端/Mock数据
  • 新建的 Enquiry 出现在 Enquiry Management 列表

1️⃣ 检查前端服务状态

2️⃣ 测试主数据加载

3️⃣ 模拟创建 Enquiry

4️⃣ 验证 Enquiry 列表

📖 手动测试步骤

  1. 在浏览器中打开 http://localhost:3000
  2. 点击 "New Enquiry" 按钮
  3. 填写表单并执行以下测试：
    • Reference Number 显示：选择产品类型后，查看 Reference Number 是否自动生成
    • CN定价管理员：验证是否为下拉框，包含选项（Admin, Manager等）
    • 销售级联：选择销售国家 → 自动加载对应的 Sales PIC → 显示 Sales Office
    • 多港口选择：在 POL 和 POD 下拉框中选择多个港口
    • POD Country映射：选择 POD 后，查看"目的港国家"字段是否自动显示国家名称
    • 指派CN办公室：确认该字段在"销售信息"区块而非基础信息
  4. 点击 "Save Enquiry" 提交
  5. 返回 Enquiry Management 列表，验证新建记录是否出现
