## 🎯 主要功能

### 1. 查看日志列表
- 表格显示所有系统操作记录
- 包含: 时间、用户、操作类型、资源类型、状态等信息

### 2. 筛选日志
在筛选条件区域设置：
- **开始日期/结束日期**: 时间范围筛选
- **用户**: 按用户名筛选
- **操作类型**: 选择 新增/修改/删除/查看/导出/登录/退出
- **资源类型**: 如 ENQUIRY, PORT, COUNTRY 等

点击 **查询** 按钮应用筛选，点击 **重置** 清除筛选。

### 3. 分页浏览
- 页面底部显示当前页码和总页数
- 点击 **上一页** / **下一页** 切换页面

### 4. 导出日志
点击右上角 **导出** 按钮，下载审计日志文件。

### 5. 刷新数据
点击 **刷新** 按钮重新加载最新数据。

### 6. 清空日志
⚠️ **管理员功能** - 点击 **清空** 按钮清空所有审计日志（不可撤销）

## 💡 提示

1. **权限**: 仅 Admin 用户可访问审计日志功能
2. **刷新**: 进行操作后点击刷新按钮查看最新日志
3. **筛选**: 可组合使用多个筛选条件
4. **导出**: 导出的文件为 JSON 格式，适合程序处理
5. **清空**: 仅在必要时使用清空功能（如定期归档后）

## 📝 常见问题

### Q: 为什么看不到Settings菜单？
A: Settings菜单仅对Admin用户可见，确保使用admin账户登录。

### Q: 导出功能下载的是什么格式？
A: 当前版本导出为JSON格式，方便程序处理。后续版本会支持Excel格式。

### Q: 审计日志会自动清理吗？
A: 当前版本不会自动清理，需要管理员手动清空或后续实现自动归档功能。

### Q: 可以看到旧的日志吗？
A: 可以，使用时间范围筛选查看历史日志，或使用分页浏览所有日志。
