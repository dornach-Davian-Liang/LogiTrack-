# 日期选择器UI设计对比与功能说明

## 旧设计 vs 新设计

### 1. 报表页面 Data Filter (Start Date & End Date)

#### 旧设计
```html
<!-- 简单的HTML date input -->
<input type="date" value="2026-02-25" />
<!-- 显示格式: mm/dd/yyyy (浏览器自動) -->
```

**问题:**
- 显示格式不一致（不同浏览器表现不同）
- 缺乏交互性
- 用户输入友好度低
- 不支持手动输入

#### 新设计
```
┌─────────────────────────────────────┐
│ Start Date                       X  │  ← 支持清除
├─────────────────────────────────────┤
│ 📅 2026/02/25                    ⌄ │  ← YYYY/MM/DD格式
├─────────────────────────────────────┤────────────────────┐
│                                        │  February 2026   │
│                                        │  ← ← [Nav] → →   │
│                                        │  Su Mo Tu We Th Fr Sa
│                                        │  1  2  3  4  5  6  7
│                                        │  ...
│                                        │  22 [23] 24 25 26 27 28
│                                        │  ...
│                                        │  [ Today ] [ Close ]
└─────────────────────────────────────┴────────────────────┘
```

**改进:**
- ✅ 统一的YYYY/MM/DD显示格式
- ✅ 展开式日期选择面板
- ✅ 支持手动输入
- ✅ 月份导航
- ✅ Today快捷按钮
- ✅ 清除功能
- ✅ 一致的跨浏览器体验

### 用户交互流程

#### 场景1: 使用日期面板选择
```
1. 用户点击输入框或日历图标
   ↓
2. 弹出日期选择面板
   ↓
3. 用户可以:
   - 点击左/右箭头导航月份
   - 直接点击日期选择
   - 点击"Today"选择今日
   - 点击"Close"关闭面板
```

#### 场景2: 手动输入日期
```
1. 用户点击输入框并开始输入
   ↓
2. 支持格式:
   - YYYY/MM/DD (推荐)
   - MM/DD/YYYY (向后兼容)
   ↓
3. 完成输入后，日期自动验证和保存
   ↓
4. 如果日期无效，输入不更新
   ↓
5. 如果超过max限制，输入不更新
```

#### 场景3: 清除日期
```
1. 用户输入日期后，X按钮显示
   ↓
2. 点击X按钮
   ↓
3. 日期立即清除，输入框变空
   ↓
4. onChange事件触发空值
```

### 支持的输入格式

| 格式 | 示例 | 支持 | 备注 |
|-----|------|------|------|
| YYYY/MM/DD | 2026/02/25 | ✅ | 推荐格式 |
| MM/DD/YYYY | 02/25/2026 | ✅ | 向后兼容 |
| YYYY-MM-DD | 2026-02-25 | ⚠️ | 内部格式，展示不含 |
| DD/MM/YYYY | 25/02/2026 | ❌ | 不支持 |
| 其他格式 | ... | ❌ | 不支持 |

### 日期验证规则

```javascript
// 有效的日期例子
✅ 2026/02/25 → 有效日期
✅ 02/25/2026 → 有效日期
✅ 1999/12/31 → 有效日期
✅ 2000/01/01 → 有效日期

// 无效的日期例子
❌ 2026/02/30 → 2月没有30号
❌ 2026/13/01 → 13月不存在
❌ 2026/00/15 → 0月不存在
❌ 12345/6 → 格式不正确
❌ 2026/2/5 → 缺少0填充（严格模式）
```

### 日期限制

当使用 `max` 属性时，用户只能选择不超过该日期的日期：

```html
<!-- 例子：只能选择今日或之前的日期 -->
<DatePickerInput
  value={date}
  onChange={setDate}
  max={new Date().toISOString().split('T')[0]}
/>
```

**表现:**
```
日期 | 年份 | 月份 | 超出范围日期
-----|------|------|----------
2026/02/20 | 可选 | 可选 | 灰显 ✗
2026/02/25 (Today) | 可选 | 可选 | 可选 ✓
2026/02/26 (Tomorrow) | 可选 | 可选 | 灰显 ✗
2026/03/* | 可选 | 可选 | 全灰显 ✗
```

## 常见问题 (FAQ)

### Q1: 为什么改用 YYYY/MM/DD？
**A:** YYYY/MM/DD遵循ISO 8601国际标准，更易理解，避免mm/dd/yyyy的歧义。

### Q2: 可以输入 MM/DD/YYYY 吗？
**A:** 可以！组件保持向后兼容，支持两种格式，自动识别。

### Q3: 支持键盘操作吗？
**A:** 支持基本操作（Tab切换、Enter确认）。可在弹出面板中使用箭头键。

### Q4: 可以禁用日期选择吗？
**A:** 可以，使用 `disabled={true}` 属性。

### Q5: 如何清除已选日期？
**A:** 点击输入框右侧的X按钮，或修改onChange回调返回空字符串。

### Q6: 支持时间选择吗？
**A:** 当前版本只支持日期选择。时间选择可作为未来扩展功能。

### Q7: 移动设备支持如何？
**A:** 完全支持移动设备，提供比系统日期选择器更一致的体验。
