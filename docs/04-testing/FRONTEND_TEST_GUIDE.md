# 前端功能测试指南

- **前端地址**: http://localhost:3000
- **后端地址**: http://localhost:8080

## 前端新功能测试清单

### 1. 增强版报表 Dashboard（带过滤）✅

**测试步骤**:
1. 登录系统
2. 点击左侧菜单 "Reports" -> "增强报表"
3. 测试过滤面板:
   - 选择日期范围（如 2026-02-01 到 2026-02-28）
   - 选择 Core Flag（CORE 或 NON_CORE）
   - 选择 CN Office（如上海）
   - 点击"应用过滤"按钮
4. 验证结果:
   - 统计卡片更新
   - CN Office 统计表显示
   - 状态分布图更新
   - 地理分布更新

**预期结果**:
- 数据根据过滤条件正确筛选
- CN Office 统计表显示带有转化率、排名
- 可以导出 CSV

---

### 2. 时期对比报告 ✅

**测试步骤**:
1. 点击左侧菜单 "Reports" -> "时期对比"
2. 选择对比类型:
   - 月度对比 或 季度对比
3. 选择要对比的时期（至少2个，最多6个）:
   - 月度: 2026-01, 2026-02
   - 季度: 2025-Q4, 2026-Q1
4. 可选：选择过滤条件
   - Core Flag: CORE
   - CN Office: SHANGHAI
5. 点击"开始对比"

**预期结果**:
- 显示汇总卡片（总询价数、平均转化率、最佳/最差时期）
- 显示详细对比表格，包含环比变化
- 显示趋势图表（折线图/柱状图切换）
- 可以导出 CSV

---

### 3. CN Office 数据透视表 ✅

**测试步骤**:
1. 在增强报表页面
2. 应用过滤查看 CN Office 统计
3. 查看统计表:
   - 排名（金银铜牌）
   - 总询价数、已报价、已确认
   - 转化率（颜色编码）
   - 趋势指示器
4. 点击"导出 CSV"

**预期结果**:
- 表格按询价数排序
- 转化率颜色编码（绿色>=30%, 黄色>=20%, 红色<20%）
- 成功导出 CSV 文件

---

### 4. 趋势图表（Recharts）✅

**测试步骤**:
1. 在时期对比报告中查看趋势图表
2. 切换图表类型:
   - 点击"📈 折线图"
   - 点击"📊 柱状图"
3. 鼠标悬停查看 Tooltip
4. 查看图表下方的洞察卡片

**预期结果**:
- 折线图和柱状图平滑切换
- Tooltip 显示详细数据
- 三条曲线/柱子（总询价数、已报价、已确认）
- 洞察卡片自动分析趋势

## API 测试（后端已验证）

### 基础 Dashboard API
```bash
GET /api/statistics/dashboard?month=2026-02
```

### 过滤 Dashboard API
```bash
GET /api/statistics/dashboard/filtered?startDate=2026-02-01&endDate=2026-02-28&coreFlags=CORE
```
**状态**: ✅ 已测试通过（2条CORE询价）

### 时期对比 API
```bash

Body: {
  "comparisonType": "MONTHLY",
  "periods": ["2026-01", "2026-02"],
  "coreFlags": ["CORE"],
  "cnOffice": "SHANGHAI"
}
```
**状态**: ✅ 已测试通过（+60%增长）

## 已知问题和限制

### 当前限制
1. 最多选择 6 个时期进行对比（防止图表过于拥挤）
2. CN Office 过滤仅支持单选（可扩展为多选）
3. 日期范围选择暂无快捷选项（可添加"最近30天"等）
